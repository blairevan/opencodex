# 账号信息展示设置设计

## 目标

在 Providers 的账号列表底部增加“展示账号信息”设置，用于控制账号卡片是否显示邮箱和账号 ID。默认开启，保持现有行为；关闭后采用隐私优先的单行显示。

## 展示规则

### 开启

- 保持当前账号主标签逻辑：有别名显示别名，否则显示现有账号标签。
- 保留邮箱和脱敏账号 ID 的辅助信息行。
- 账号额度、健康状态、启用状态、折叠和操作按钮不受影响。

### 关闭

- 有非空别名：只显示一行别名。
- 没有别名但有邮箱：取邮箱 `@` 前的用户名，按“前 2 位 + `***` + 后 2 位”显示。
- 没有别名且没有邮箱：回退到现有安全账号标签，避免显示原始账号 ID。
- 隐藏邮箱、账号 ID 以及当前账号信息辅助行；健康状态提示仍按原有逻辑展示。

## 状态与数据流

- 设置属于 GUI 展示偏好，使用浏览器 `localStorage` 保存，刷新页面后保持。
- 默认值为 `true`，兼容现有界面。
- 不新增后端 API，不写入 OpenCodex 运行配置，不保存或传输凭据。
- 账号显示函数接收展示偏好，统一负责主标签和辅助行是否出现，避免在 JSX 中分散判断。

## 页面位置

设置区放在账号列表及账号导入/添加操作之后，作为账号区域底部的独立设置行。使用现有开关样式和 i18n 体系，文案需补齐全部语言文件。

## 测试与验收

- 单元测试覆盖：别名优先、邮箱用户名脱敏、短用户名、缺少邮箱的安全回退。
- GUI 构建必须通过。
- i18n 校验必须覆盖新增文案。
- 手工验收：开关默认开启；关闭后有别名只剩一行别名；关闭后无别名只剩脱敏用户名；刷新页面后开关状态保持；额度和账号操作仍正常。

## 风险与边界

- `localStorage` 仅保存布尔展示偏好，不保存邮箱、账号 ID、Token 或额度。
- 账号别名是用户主动设置的展示名，关闭隐私展示时仍按明确需求展示。
- 邮箱用户名长度不足 4 个字符时，不重复暴露完整用户名，使用安全占位形式。
